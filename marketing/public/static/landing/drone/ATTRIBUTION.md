# Aerial imagery

`alameda-aerial.jpg` is USGS / NAIP orthoimagery of Alameda Point, California, retrieved from the USGS National Map Imagery Only service on October 22, 2026.

Source: https://basemap.nationalmap.gov/arcgis/rest/services/USGSImageryOnly/MapServer

The image is a fixed geographic backdrop. Routes, boundaries, aircraft, weather, telemetry, observations and mission states displayed over it are illustrative product-demo data, not live operational information. The website retains visible USGS / NAIP attribution.

Export parameters: EPSG:3857, bounding box `-13616896.361103779,4547807.742474465,-13612296.361103779,4550669.742474465`, 1800 × 1120 pixels.

The USGS service describes continental-US imagery as public domain. See https://www.usgs.gov/the-national-map-data-delivery for National Map data delivery information.
