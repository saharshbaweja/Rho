# Rho — Next.js market-infrastructure site

A premium multi-page Next.js prototype for Rho, inspired by the editorial/financial-market quality of Ornn while using original Rho branding, copy, visuals, and motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Pages
- `/` Home
- `/product/` Rho Trials / platform
- `/index/` Rho Index
- `/about/` About
- `/contact/` Contact

All market/index values are illustrative prototype data and are labeled accordingly.
